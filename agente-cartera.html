Conectar con el Liquidador / Sistema GTC (siguiente fase)

Cuando el flujo esté listo — Auditor Documental detecta la factura → Liquidador registra los datos completos de la operación — este panel puede leer esos mismos datos automáticamente, sin que nadie vuelva a digitarlos aquí. Para eso se necesita que el Liquidador guarde cada operación cerrada en una clave de localStorage con esta forma (o se me indique el nombre real de la clave que ya usa):

localStorage.setItem('gtc_cartera_operaciones', JSON.stringify([ { cliente: "CI Empaquetadora del Norte SAS BIC", fondeador: "Coltefinanciera", factura: "116", valorFacial: 2999981712, fechaEmision: "2026-08-03", fechaVencimiento: "2027-01-30", estado: "ACTIVA", observaciones: "" } ]));

Dime cuál es el nombre exacto de la clave (o el archivo) donde el Liquidador ya guarda las operaciones cerradas, y ajusto este agente para que lea directamente de ahí — sin tener que cambiar nada más de lo que ya construimos.
